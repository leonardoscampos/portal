## Framework SLSA

O SLSA (Supply chain Levels for Software Artifacts) define quatro níveis de integridade da cadeia de suprimentos.

| Nível | Requisitos | Controles principais |
|-------|------------|----------------------|
| **SLSA 1** | Processo de build documentado | Proveniência gerada (não assinada) |
| **SLSA 2** | Serviço de build hospedado | Proveniência assinada; código-fonte versionado |
| **SLSA 3** | Build isolado e auditável | CI reforçado; sem runners auto-hospedados gravando proveniência |
| **SLSA 4** | Revisão por duas pessoas; build hermético | Reproduzível; todas as dependências fixadas por digest |

## Sigstore — Assinatura Sem Chave

O Sigstore é um projeto CNCF que oferece assinatura gratuita, transparente e sem chave por meio de identidade OIDC (GitHub Actions, Google, Microsoft).

```
Developer/CI                Sigstore stack
    │                            │
    │  1. Request OIDC token      │
    │  (GitHub Actions job ID)    │
    │ ──────────────────────────▶ │  Fulcio CA
    │  2. Short-lived cert        │  (issues cert bound to OIDC identity)
    │ ◀────────────────────────── │
    │  3. Sign artifact           │
    │  4. Publish to Rekor log ──▶│  Rekor (transparency log)
    │  (immutable, append-only)   │
```

### cosign — Assinar e Verificar

```bash
# Install cosign
brew install cosign

# ─── Keyless signing (GitHub Actions / OIDC) ─────────────────────────────

# Sign an image (keyless — uses OIDC from environment)
cosign sign --yes ghcr.io/my-org/my-app:1.2.3

# Sign by digest (immutable reference)
cosign sign --yes ghcr.io/my-org/my-app@sha256:abc123...

# Verify keyless signature
cosign verify \
  --certificate-identity "https://github.com/my-org/my-repo/.github/workflows/release.yaml@refs/heads/main" \
  --certificate-oidc-issuer "https://token.actions.githubusercontent.com" \
  ghcr.io/my-org/my-app:1.2.3

# ─── Key-based signing (for air-gapped / regulated environments) ──────────

# Generate key pair
cosign generate-key-pair --kms awskms:///arn:aws:kms:us-east-1:123456789012:key/mrk-xxx
# or local (store private key in Vault):
cosign generate-key-pair

# Sign with key
cosign sign --key cosign.key ghcr.io/my-org/my-app:1.2.3

# Verify with public key
cosign verify --key cosign.pub ghcr.io/my-org/my-app:1.2.3
```

### Anexar Atestações (SBOM, Proveniência, SAST)

```bash
# Generate SBOM with Syft
syft ghcr.io/my-org/my-app:1.2.3 -o spdx-json > sbom.spdx.json

# Attach SBOM as attestation
cosign attest --yes \
  --predicate sbom.spdx.json \
  --type spdxjson \
  ghcr.io/my-org/my-app:1.2.3

# Attach SLSA provenance (generated by GitHub Actions slsa-framework)
cosign attest --yes \
  --predicate provenance.json \
  --type slsaprovenance \
  ghcr.io/my-org/my-app:1.2.3

# Verify attestation
cosign verify-attestation \
  --certificate-identity "..." \
  --certificate-oidc-issuer "https://token.actions.githubusercontent.com" \
  --type spdxjson \
  ghcr.io/my-org/my-app:1.2.3 | jq .payload -r | base64 -d | jq
```

## SBOM (Lista de Materiais de Software)

### Gerando SBOMs

=== "Syft"

    ```bash
    # Install
    brew install syft

    # Generate from image
    syft ghcr.io/my-org/my-app:1.2.3 -o spdx-json > sbom.spdx.json
    syft ghcr.io/my-org/my-app:1.2.3 -o cyclonedx-json > sbom.cdx.json

    # Generate from directory
    syft dir:. -o spdx-json > sbom.spdx.json

    # Generate from binary (even without source)
    syft packages file:./my-binary -o table
    ```

=== "Trivy"

    ```bash
    # SBOM from image
    trivy image --format spdx-json --output sbom.spdx.json my-app:latest
    trivy image --format cyclonedx --output sbom.cdx.json  my-app:latest

    # SBOM from IaC
    trivy config --format cyclonedx . > iac-sbom.cdx.json

    # Scan an existing SBOM for vulnerabilities
    trivy sbom sbom.spdx.json
    ```

### Formatos de SBOM

| Formato | Órgão padrão | Melhor para |
|---------|--------------|-------------|
| **SPDX** | Linux Foundation | Open Source, conformidade legal |
| **CycloneDX** | OWASP | Focado em segurança, suporte rico a VEX |
| **Syft JSON** | Anchore | Cadeia de ferramentas interna |

### VEX — Vulnerability Exploitability eXchange

```json
// vex.cdx.json — document which CVEs are NOT exploitable
{
  "bomFormat": "CycloneDX",
  "specVersion": "1.5",
  "version": 1,
  "vulnerabilities": [
    {
      "id": "CVE-2023-12345",
      "analysis": {
        "state": "not_affected",
        "justification": "code_not_reachable",
        "detail": "The vulnerable code path is never called in our binary (dead code)"
      },
      "affects": [
        { "ref": "pkg:golang/github.com/example/lib@1.0.0" }
      ]
    }
  ]
}
```

## GitHub Actions — Proveniência SLSA

```yaml
name: Release with SLSA Provenance

on:
  push:
    tags: ["v*"]

jobs:
  build:
    runs-on: ubuntu-latest
    outputs:
      image-digest: ${{ steps.build.outputs.digest }}
    permissions:
      contents: read
      packages: write
    steps:
      - uses: actions/checkout@v4

      - name: Build and push image
        id: build
        uses: docker/build-push-action@v6
        with:
          push: true
          tags: ghcr.io/my-org/my-app:${{ github.ref_name }}
          outputs: type=registry

  # SLSA provenance — SLSA level 3 via slsa-framework generator
  provenance:
    needs: [build]
    permissions:
      actions: read
      id-token: write
      packages: write
    uses: slsa-framework/slsa-github-generator/.github/workflows/generator_container_slsa3.yml@v2.0.0
    with:
      image: ghcr.io/my-org/my-app
      digest: ${{ needs.build.outputs.image-digest }}
    secrets:
      registry-username: ${{ github.actor }}
      registry-password: ${{ secrets.GITHUB_TOKEN }}

  # Sign image + attach SBOM
  sign:
    needs: [build, provenance]
    runs-on: ubuntu-latest
    permissions:
      id-token: write
      packages: write
    steps:
      - uses: sigstore/cosign-installer@v3

      - name: Sign image
        run: |
          cosign sign --yes \
            ghcr.io/my-org/my-app@${{ needs.build.outputs.image-digest }}

      - name: Generate and attach SBOM
        run: |
          syft ghcr.io/my-org/my-app@${{ needs.build.outputs.image-digest }} \
            -o spdx-json > sbom.spdx.json
          cosign attest --yes \
            --predicate sbom.spdx.json \
            --type spdxjson \
            ghcr.io/my-org/my-app@${{ needs.build.outputs.image-digest }}
```

## Autorização Binária (GKE)

```bash
# Enable Binary Authorization on GKE cluster
gcloud container clusters update prod-cluster \
  --enable-binauthz \
  --region us-east1

# Create an attestor (ties to cosign / Kritis)
gcloud container binauthz attestors create prod-signer \
  --attestation-authority-note=projects/my-project/notes/prod-signer-note \
  --attestation-authority-note-project=my-project
```

```yaml
# Binary Authorization policy — require attestation before deploy
defaultAdmissionRule:
  evaluationMode: ALWAYS_DENY          # deny unless attested
  enforcementMode: ENFORCED_BLOCK_AND_AUDIT_LOG

clusterAdmissionRules:
  us-east1.prod-cluster:
    evaluationMode: REQUIRE_ATTESTATION
    enforcementMode: ENFORCED_BLOCK_AND_AUDIT_LOG
    requireAttestationsBy:
      - projects/my-project/attestors/prod-signer

admissionWhitelistPatterns:
  - namePattern: gcr.io/google-containers/*
  - namePattern: gcr.io/gke-release/*
  - namePattern: registry.k8s.io/*
```

## Segurança de Dependências

### Renovate — Atualizações Automáticas de Dependências

```json
// renovate.json
{
  "$schema": "https://docs.renovatebot.com/renovate-schema.json",
  "extends": ["config:recommended"],
  "schedule": ["before 6am on Monday"],
  "packageRules": [
    {
      "matchUpdateTypes": ["patch"],
      "automerge": true
    },
    {
      "matchPackagePatterns": ["^aws-sdk"],
      "groupName": "AWS SDK packages"
    }
  ],
  "vulnerabilityAlerts": {
    "enabled": true,
    "labels": ["security"],
    "automerge": true
  },
  "osvVulnerabilityAlerts": true
}
```

### Fixação de Dependências por Digest

```dockerfile
# Pin base image by digest — immune to tag mutation
FROM node:20.15.0-alpine@sha256:bf77dc26e48ea95fca9d1aceb5acfa69d2e546b765ec2abfb502975f1a2d4def AS base
```

```yaml
# GitHub Actions — pin actions by commit SHA
- uses: actions/checkout@11bd71901bbe5b1630ceea73d27597364c9af683  # v4.2.2
- uses: docker/build-push-action@5cd11c3a4ced054e52742c5fd54dca954e0edd85 # v6.7.0
```

```hcl
# Terraform — pin provider versions exactly
terraform {
  required_providers {
    aws = {
      source  = "hashicorp/aws"
      version = "= 5.62.0"   # exact pin, not ~>
    }
  }
}
```
